# SHAPES THAT MUST NEVER BE IN THE TWO TABLES, which enter the PUBLIC mallet_estimator repository
# (design-marathi §3.3, I18nTableTest check 8). name<TAB>Java regex. Every string in both files is checked --
# keys, values, reviewer notes and locations alike (a key is built from the English and never renamed, so it
# outlives a reworded text). A match fails the build naming the key and the pattern, never the matched text,
# because CI logs of a public repository are public too; when a KEY matches, only the entry's position is named.
# These patterns need no secret, and they are ALL a fork, a pull request or a run without the I18N_DENY_NAMES
# secret gets: they catch figures, emails and phone numbers, and they CANNOT catch a client's name. Names are
# checked only when a client-name list is present (the I18N_DENY_NAMES secret on CI, -Pi18n.deny=<file>
# locally; never committed), and a run without one says so with a ::warning in its log.
# email, phone, landline, digits10 and currency are required; the test proves each still catches its own examples.
email	[A-Za-z0-9._%+-]+@[A-Za-z0-9-]+(?:\.[A-Za-z0-9-]+)*\.[A-Za-z]{2,}
phone	(?<![\d.])(?:(?:\+?91|0)[\s-]?)?[6-9](?:[\s-]?\d){9}(?![\d.])
landline	(?<![\d.])0\d{2,4}[\s-]?\d{3,4}[\s-]?\d{4}(?![\d.])
digits10	(?<![\d.])\d{10,}(?![\d.])
currency	(?i)(?:₹|(?<![a-z])(?:rs|inr))\.?\s?\d|\d[\d,]*\s?/-
lakh	(?i)\d+(?:\.\d+)?\s?(?:lakh|lakhs|lac|lacs|crore|crores)(?![a-z])
grouped	(?<![\d,.])\d{1,2}(?:,\d{2})+,\d{3}(?![\d,])
pincode	(?<![\d.])4[01]\d{4}(?![\d.])
